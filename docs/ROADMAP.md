### champs.pokedb.tokyo 벤치마킹 (조사 2026-07-23)

일본어 비공식 챔피언스 랭크 배틀 집계 사이트. 자세한 내용은 해당 세션 대화
참고. 아래에서 하나씩 골라 이슈로 승격해 작업한다.

**중요**: 챔피언스에는 **테라스탈 메커니즘이 없다** — championsbattledata.com의
포켓몬별 채용률 CSV(기술/지닌도구/팀메이트/성격/노력치/특성 항목을 전부
나열하는 소스)에 테라스탈 카테고리가 없음을 확인(2026-07-23). pokedb.tokyo가
상세 페이지 문구에 "テラスタイプ"를 언급한 건 범용 템플릿 문구로 보이며
챔피언스엔 해당하지 않을 가능성이 큼. 메가진화는 실재(레귤레이션 태그로 확인).

**데이터 (우선순위 순)**

- [x] **championsbattledata.com 채용률 연동**: 로스터 인제스트와 같은 소스가
      제공하는 자체 JSON API(`/api/battle/{Singles|Doubles}/{showdownId}`,
      문서 `/api_guide`)로 종(species) 단위 채용률 스냅샷을 받아
      `src/lib/data/usage.json`에 저장(`npm run usage`, `scripts/add-usage.mjs`,
      233/235종 성공, API 일시 실패는 재시도로 흡수). 포켓몬 상세 페이지에
      **채용률** 섹션(`UsageSection`, 카드 UI)으로 기술·지닌도구·특성·성격·
      노력치 분배·자주 쓰는 팀원을 막대그래프로 표시. 이름 로컬라이즈: 성격
      25종은 PokéAPI→`src/lib/natureNames.ts` 코드 상수, 지닌도구는 ingest 시
      PokéAPI로, 팀원은 로스터로 usage.json에 한/영/일 저장(챔피언스 오리지널
      메가스톤은 본가에 없어 `{종}나이트` 규칙으로 구성). 시즌 M-1~M-4 표시는
      아직(아래 항목).
- [ ] **pokedb.tokyo 오픈데이터 CSV/JSON 연동**: `/guide/opendata`에서 명시적

- [ ] **시즌/레귤레이션 표시**: M-1~M-4 같은 시즌 날짜 범위, 레귤레이션(메가진화
