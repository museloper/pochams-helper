# 로드맵

AI와 협업할 때 이 문서가 작업의 기준이 된다.
작업을 시작하면 해당 항목에 `(진행 중)`을 붙이고, 끝나면 체크한다.
새 아이디어는 우선 Backlog에 추가하고, 우선순위를 정한 뒤 Milestone으로 옮긴다.
